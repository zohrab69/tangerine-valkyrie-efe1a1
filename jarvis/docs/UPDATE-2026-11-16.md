# Update 2026-11-16: daily products, JARVIS agent, 24/7, check my idea

What changed is listed in `ROADMAP.md` (top section). This page gives your steps, one at a time.
Everything below runs in **PowerShell** on your laptop, or in the browser. Never paste a key or password into a chat.

## Step 1. Get the new files onto the server (PowerShell)
```powershell
$IP = "2.29.114.208"
cd $HOME\jarvis-repo; git pull
scp -r $HOME\jarvis-repo\jarvis\infra\server\* root@${IP}:/root/jarvis-server/
```

## Step 2. Rebuild the voice service (now also makes videos), about 5-10 minutes
```powershell
ssh root@$IP "bash /root/jarvis-server/voice-setup.sh"
```
Your screen password and key stay the same. At the end it says `voice service: {"status":"ok"}`.

## Step 3. 24/7: watchdog, backups and the off-server copy
```powershell
ssh root@$IP "bash /root/jarvis-server/ops-247.sh"
ssh -t root@$IP "bash /opt/jarvis/offsite-setup.sh"
```
- The first command prints a table of containers (all must say `restart=unless-stopped`) and the address for UptimeRobot.
- The second asks for your **Telegram bot token** (from @BotFather, `/mybots` → JARVIS → API Token). Paste it **in the black SSH window only**; it stays hidden.
  Then it shows a **backup key**: copy it into your password manager, then press Enter. A test message and your first encrypted backup arrive on Telegram.

## Step 4. Outside watchdog (browser, 3 minutes, free)
1. Create a free account on uptimerobot.com.
2. **New monitor** → type **HTTP(s)** → URL: the address printed in step 3 (ends with `/healthz/readiness`) → interval **5 minutes**.
3. Alert contact: your email. Optional: install the UptimeRobot app on your phone for push alerts.

## Step 5. Keys in n8n (browser: your n8n address → Credentials → Add credential)
1. **SerpApi** (if not done yet): sign up free at serpapi.com → copy your API key → n8n credential type **Query Auth**, name the credential `SerpApi`,
   Name `api_key`, Value = your key.
2. **OmniRoute (OpenAI format)** for the agent: credential type **OpenAI**. API Key = the OmniRoute API key you made for n8n (OmniRoute dashboard → API Keys;
   you can make a new one), **Base URL** `http://omniroute:20128/v1`. Name it `OmniRoute (OpenAI format)`.
3. **Shopify** (to list products and read orders). Since 2026 Shopify no longer gives a permanent key to new stores' apps: you create an app in the
   **Dev Dashboard** and JARVIS gets a fresh 24-hour key himself with its Client ID and Secret.
   1. Shopify admin → Settings → Apps → **Develop apps** → **Build apps in Dev Dashboard** (or open dev.shopify.com/dashboard, same login).
   2. **Create app** → name `JARVIS` → create it in the Dev Dashboard.
   3. In the app's version/configuration: **Access scopes** `read_orders`, `read_products`, `write_products`, `read_publications`, `write_publications` → **Release**.
   4. **Install** the app on the store `rangeo-ca`.
   5. App **Settings**: copy the **Client ID** and the **Client secret**.
   6. In n8n: credential type **Custom Auth**, name `Rangéo Shopify app`, JSON (put your two values between the quotes):
      `{"body": {"grant_type": "client_credentials", "client_id": "PASTE", "client_secret": "PASTE"}}`

For each file: **Create workflow** (empty) → ⋯ → **Import from File** → open every node with a ⚠️ or a credential and pick the right one
(n8n may pick the wrong credential on its own) → **Save** → **Publish**. Files are in `jarvis-repo\jarvis\workflows\`.

| Order | File | Unpublish first | Credentials to check |

| 2 | `jarvis-research-v2.json` | Research v1 | CJ API key, SerpApi, OmniRoute, JARVIS Telegram, JARVIS screen key (webhook) |
| 3 | `jarvis-briefing-v2.json` | Briefing v1 | OmniRoute, JARVIS Telegram, JARVIS screen key (webhook) |
| 4 | `jarvis-idea-v1.json` | (none) | JARVIS screen key, CJ API key, SerpApi, OmniRoute, Rangéo Shopify app (in *Shopify token*), JARVIS Telegram |
| 4b | `jarvis-shop-v2.json` | Shop v1 (if imported) | Rangéo Shopify app (in *Shopify token*), JARVIS Telegram |
| 5 | `jarvis-brain-v1.json` | **Telegram v5 and Voice v1** | OmniRoute (OpenAI format) in *OmniRoute chat model*; JARVIS screen key in both webhooks and in every tool that calls `localhost:5678`; JARVIS Telegram; CJ API key |

Then, in each JARVIS workflow: **Settings → Error workflow → JARVIS Alerts v2** → Save.
